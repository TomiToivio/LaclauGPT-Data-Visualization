# AI26 visualization reference case

AI26 (`Ideological contestation over AI`) is the preferred realistic public example for LaclauGPT Data Visualization. It is the empirical case developed alongside the current public paper, but Visualization must remain generic and render canonical records from any study.

## Public dashboard semantics

The reference AI26 dashboard should make the three paper arenas first-class filters:

- `elites` — AI labs, entrepreneurs, researchers, intellectuals and adjacent movements;
- `grassroots` — mobilisation around employment, creative work, surveillance, data extraction, data centres, environment, safety and broader support/opposition;
- `parliamentary` — parliamentary, electoral, party, government and policy discourse.

Arena membership is sampling provenance, not ideology.

Useful public filters/views include:

- date/time and source platform;
- arena, country/language and author/entity;
- candidate signifier;
- provisional formation;
- review state and uncertainty/abstention;
- evidence-linked demands, articulations and relations;
- collective subjects / Us / Frontier candidates;
- sociotechnical-imaginary candidates;
- event/location timeline where evidence exists;
- discourse graph/network projection;
- raw/intermediate/current/human-readable four-layer drill-down.

## Formation display

For reproducible aggregation the current AI26 formation vocabulary is:

`accelerationism`, `doomerism`, `left-wing accelerationism`, `ai safety`, `ai critical`, `anti-ai`.

These labels are provisional sensitising categories. The UI must not present them as exhaustive, mutually exclusive or permanent actor identities. Multi-label assignments, `uncertain`/unclassified states and human corrections must remain visible.

## Current candidate signifiers

As of 2026-09-16, useful public AI26 views include longitudinal comparison around:

`safety`, `pacing`, `competition`, `innovation`, `China`, `control`, `liability`, `independent evaluation`, `standards`, `regulation`, `national security`, `labour`, `job displacement`, `automation`, `ownership`, `open source`, `surveillance`, `copyright`, `creative work`, `data centres`, `energy`, `environment`, `democracy`, `abundance`, `existential risk`.

These are candidate signifiers/context terms. A chart must not imply that frequency establishes a nodal point, that semantic ambiguity establishes floating/empty signification, or that negative sentiment establishes antagonism.

## Current pacing/safety controversy

The September 2026 frontier-AI debate is a useful reference visualization because the same actors and organizations can articulate multiple, partially conflicting logics over time. Suggested visualizations include:

- time series of evidence-linked uses of `safety`, `pacing`, `competition`, `innovation`, `control` and `regulation`;
- actor-signifier relation graphs;
- arena comparison of demands and future imaginaries;
- reviewable document drill-down showing the source evidence behind each proposed relation.

Do **not** hard-code current public figures or organizations to a permanent formation. The analytical point is relational change.

## Privacy boundary

This public repository may contain dashboard configuration examples, labels, public codebook vocabulary and synthetic records. Never commit the real AI26 dataset, transcripts, OCR, frame captures, researcher annotations, private watch lists, credentials, private endpoints or generated private reports.
